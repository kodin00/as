Addin Satria A B C D E

I'm a software engineer who builds backend systems and the tools that keep them running.

I've been writing software professionally for about eight years, mostly on the layer where products actually live: APIs, queues, databases, and the pipelines between them. These days I work on platform and infrastructure, making it easier for other engineers to ship without worrying about what's underneath.

I believe a system that needs a hero is a broken system. I build for the person who gets paged at 3 a.m., which is usually me, so I care about good defaults, loud failures, and docs that tell the truth. The best compliment I get is when someone forgets my service exists.

I like small teams, clear ownership, and code reviews that leave both the code and the reviewer better. I'd rather delete a feature than maintain one nobody uses, and I always ask for the number before I agree that something is slow.

Outside work I mentor junior engineers, write the occasional post about systems design, and spend far too long tuning my dotfiles. I'm based in Jakarta and currently open to new roles, remote or hybrid.
